# InstructionConstructorWEB

Веб-приложение для создания, управления и прохождения интерактивных пошаговых инструкций.

Полная техническая документация находится в папке [Docs](Docs/README.md).

## Быстрый запуск

```bash
docker compose -f Docker-compose.yml up -d --build
```

## Технологии

Python, FastAPI, SQLAlchemy Async, PostgreSQL, SQLAdmin, Vue.js, Vite, Nginx, Docker Compose.

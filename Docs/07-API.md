# 07. API

## Общая информация

Backend предоставляет HTTP API на FastAPI. API используется Frontend для получения и изменения данных.

FastAPI формирует OpenAPI-описание. При локальном запуске документация Swagger UI обычно доступна по адресу:

`http://localhost:8000/docs`

JSON-схема:

`http://localhost:8000/openapi.json`

## Базовые правила

- Запросы и ответы API должны использовать согласованный формат данных.
- Для каждой операции следует проверять входные данные.
- При ошибках необходимо возвращать подходящий HTTP-статус.
- Идентификаторы UUID должны передаваться в корректном формате.
- Нельзя считать успешным изменение данных до подтверждения транзакции БД.

## Известные области API

По структуре проекта и ранее рассматривавшемуся OpenAPI известны маршруты, связанные с инструкциями. Точные пути и HTTP-методы необходимо брать из текущего `openapi.json`, поскольку префиксы роутеров могли меняться.

| Область | Назначение |
|---|---|
| Instructions | Получение и работа с инструкциями |
| Steps | Работа с шагами, если соответствующие маршруты подключены |
| Progress | Сохранение и получение прогресса, если соответствующие маршруты подключены |
| Analytics | Получение аналитических данных, если API-роутер аналитики подключён |

## Как получить точный список маршрутов

1. Запустить Backend.
2. Открыть `http://localhost:8000/docs`.
3. Проверить список операций, методы и схемы.
4. Либо открыть `http://localhost:8000/openapi.json`.
5. Обновить этот документ после изменения API.

## Типовые HTTP-статусы

| Код | Значение |
|---|---|
| `200 OK` | Запрос успешно обработан |
| `201 Created` | Ресурс создан |
| `204 No Content` | Операция выполнена без тела ответа |
| `400 Bad Request` | Некорректный запрос |
| `401 Unauthorized` | Требуется аутентификация |
| `403 Forbidden` | Недостаточно прав |
| `404 Not Found` | Ресурс не найден |
| `422 Unprocessable Entity` | Ошибка валидации данных |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

Фактические коды зависят от конкретного обработчика.

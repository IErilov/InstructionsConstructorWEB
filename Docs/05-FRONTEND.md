# 05. Frontend

## Назначение

Frontend — клиентская часть InstructionConstructorWEB. Она предоставляет пользователю интерфейс для работы с инструкциями и взаимодействует с Backend через HTTP API.

## Используемые технологии

- **Vue.js** — компонентный пользовательский интерфейс.
- **Vite** — инструмент разработки и сборки.
- **JavaScript** — клиентская логика.
- **HTML** — структура интерфейса.
- **CSS** — оформление и адаптивность.

## Основные обязанности

- Отображать доступные страницы и инструкции.
- Представлять содержимое шагов.
- Обрабатывать действия пользователя.
- Отправлять запросы к Backend.
- Отображать результаты запросов.
- Показывать состояния загрузки и ошибки.

## Взаимодействие с Backend

Клиентская часть обращается к серверу по HTTP. В Docker-конфигурации запросы могут проходить через Nginx, который проксирует API-запросы на Backend.

Рекомендуется хранить базовый адрес API в конфигурации окружения Frontend, а не дублировать его в компонентах.

## Состояния интерфейса

Для сетевых операций следует предусмотреть:

- Состояние загрузки.
- Успешное получение данных.
- Пустой результат.
- Ошибку запроса.
- Недоступность сервера.

## Сборка

Команды Frontend определяются скриптами в `Frontend/package.json`. Типичные команды Vite:

```bash
npm install
npm run dev
npm run build
```

Используйте именно те команды, которые объявлены в `package.json` проекта.

## Рекомендации по разработке

- Разделять интерфейс на переиспользуемые компоненты.
- Не размещать бизнес-логику базы данных в Frontend.
- Обрабатывать ошибки API.
- Проверять интерфейс на разных размерах экрана.
- Не хранить секреты и пароли в клиентском коде.

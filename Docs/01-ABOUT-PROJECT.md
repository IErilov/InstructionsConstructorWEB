# 01. О проекте

## Назначение

**InstructionConstructorWEB** — веб-приложение для создания, управления и прохождения интерактивных пошаговых инструкций.

Система предназначена для двух основных сценариев:

1. Администратор управляет инструкциями и анализирует статистику их прохождения.
2. Пользователь открывает инструкцию, выполняет её шаги и сохраняет прогресс.

## Проблема и решение

Обычная текстовая инструкция не всегда позволяет определить, какие этапы пользователь выполнил и на каком этапе прекратил работу. Пошаговая структура и фиксация прогресса позволяют отслеживать выполнение на уровне отдельных шагов.

## Основные понятия

| Термин | Значение |
|---|---|
| Инструкция (`Instruction`) | Набор шагов, объединённых одной целью |
| Шаг (`Step`) | Отдельный этап инструкции |
| Прогресс (`Progress`) | Запись о прохождении пользователем конкретного шага |
| Анонимный пользователь | Посетитель, учитываемый через `anonymous_id` |
| Завершение шага | Событие, фиксируемое через `completed_at` |

## Сценарий администратора

1. Администратор открывает административную панель.
2. Выбирает инструкцию или создаёт новую.
3. Управляет шагами инструкции.
4. Открывает раздел аналитики.
5. Анализирует общие показатели и статистику отдельных шагов.

## Сценарий пользователя

1. Пользователь открывает инструкцию.
2. Изучает текущий шаг.
3. Выполняет необходимые действия.
4. Завершает шаг.
5. Продолжает прохождение инструкции.

Конкретные элементы пользовательского интерфейса и переходы следует сверять с текущей реализацией Frontend.

## Цели проекта

- Упростить создание и сопровождение инструкций.
- Представить инструкцию в виде последовательности шагов.
- Сохранять прогресс прохождения.
- Предоставить администратору статистику.
- Выявлять шаги, на которых пользователи чаще прекращают прохождение.
- Обеспечить удобный запуск приложения в контейнерах.

## Область применения

Платформа может использоваться там, где необходимо представить процесс в виде последовательных действий: обучение, ознакомление с процедурами, пользовательские инструкции и внутренние регламенты.

# 04. Backend

## Назначение

Backend реализован на Python с использованием FastAPI. Он отвечает за обработку запросов, бизнес-логику, взаимодействие с PostgreSQL и предоставление API для Frontend.

## Основные технологии

- **Python** — язык серверной разработки.
- **FastAPI** — HTTP API и обработка запросов.
- **SQLAlchemy Async** — асинхронная работа с базой данных.
- **PostgreSQL** — постоянное хранение данных.
- **SQLAdmin** — административная панель.

## Организация кода

В проекте используются следующие логические части:

| Часть | Назначение |
|---|---|
| `Models/` | ORM-модели таблиц |
| `Routers/` | Маршруты API |
| `Admin/` | Представления и настройки административной панели |
| `db.py` | Базовая конфигурация БД и SQLAlchemy |
| `main.py` | Создание и настройка FastAPI-приложения |

Фактический набор файлов может отличаться.

## Асинхронная работа с БД

Для выполнения запросов используется асинхронная сессия SQLAlchemy. Типовой шаблон:

```python
async with async_session() as session:
    result = await session.execute(select(SomeModel))
    objects = result.scalars().all()
```

После изменения данных необходимо корректно завершать транзакцию:

```python
session.add(new_object)
await session.commit()
```

При возникновении ошибки транзакцию следует откатить:

```python
await session.rollback()
```

## ORM-модели

В известной реализации используются модели:

- `Instruction` — инструкция.
- `Step` — шаг инструкции.
- `Progress` — прогресс пользователя.

Подробности описаны в [документе о базе данных](06-DATABASE.md).

## Обработка ошибок

Backend должен возвращать подходящие HTTP-статусы и не раскрывать пользователю внутренние сведения о базе данных или конфигурации сервера.

Рекомендуется централизованно обрабатывать:

- Некорректные входные данные.
- Отсутствующие записи.
- Нарушения ограничений БД.
- Ошибки подключения к PostgreSQL.
- Необработанные исключения.

## Документация API

FastAPI формирует OpenAPI-схему. При локальном запуске Swagger UI обычно доступен по адресу:

`http://localhost:8000/docs`

Актуальный список маршрутов следует смотреть в Swagger UI или в `openapi.json`.

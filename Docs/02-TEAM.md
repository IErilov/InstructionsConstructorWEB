# 02. Команда разработки

Проект InstructionConstructorWEB разрабатывается командой из трёх человек.

## Ерилов Илья — Backend-разработчик

Зона ответственности:

- Разработка серверной части приложения.
- Реализация API на FastAPI.
- Разработка бизнес-логики.
- Работа с PostgreSQL через SQLAlchemy.
- Создание и сопровождение ORM-моделей.
- Интеграция Backend с Frontend.
- Поддержка серверной инфраструктуры.

## Говохин Вадим — дизайнер, Frontend-разработчик

Зона ответственности:

- Проектирование пользовательского интерфейса.
- Разработка визуальной структуры страниц.
- Подбор и согласование визуального стиля.
- Реализация клиентской части на Vue.js.
- Интеграция интерфейса с Backend API.
- Улучшение удобства взаимодействия пользователя с приложением.

## Егор Агафонов — тестировщик

Зона ответственности:

- Проверка пользовательских сценариев.
- Тестирование создания и прохождения инструкций.
- Проверка корректности сохранения прогресса.
- Проверка административной панели и аналитики.
- Поиск и описание ошибок.
- Повторное и регрессионное тестирование после исправлений.

## Совместная работа

Backend обеспечивает обработку данных и бизнес-логику, Frontend предоставляет интерфейс, а тестирование помогает проверить корректность приложения и обнаружить дефекты до выпуска изменений.

## Формат отчёта об ошибке

При обнаружении ошибки рекомендуется указать:

1. Краткое название.
2. Версию приложения и способ запуска.
3. Шаги для воспроизведения.
4. Фактический результат.
5. Ожидаемый результат.
6. Скриншот, лог или traceback, если они доступны.
